# Day 2026-10-19 — GVU Speech-Biomarker Risk Prototype

Self-improving Generator–Verifier–Updater loop for early dementia risk scoring from short speech samples.

## Opportunity
Diagnostics/Biosensors: passive multi-feature speech biomarkers (pause, hesitation, lexical diversity) that reject single-cue false positives.

## Run
```bash
python3 gvu_speech_risk.py
```

No external dependencies. Logs before/after risk scores across 2–3 improvement passes.
